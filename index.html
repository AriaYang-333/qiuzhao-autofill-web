Why

秋招填表，到底有多折磨

同一份简历，要在十几家公司的校招系统里机械地重填一遍。

重复填表

姓名、教育、实习、项目……几十个字段，每家系统重填一遍，机械、枯燥、费时。

选项类卡死

下拉、单选、城市多选、日期日历……大量非文本字段只能手动一个个点，极易漏填错填。

怕填错漏填

手填到深夜眼睛都花了，还总担心哪个必填项漏了、哪个选项点错，提心吊胆。

Features

核心功能

不是通用脚本，而是针对每家校招系统的表单结构逐一攻破。

全字段一键填充

文本、下拉、单选、多选、日期日历、文件上传区，覆盖简历全板块，一次到位。

大厂深度适配

针对 Moka / 北森 Phoenix / 飞书 ud__select / 京东 Ant Design / 腾讯 / 拼多多 等组件库定制策略。

多轮智能补填

一轮填完自动核验、缺哪补哪，多轮迭代把完成度稳定推到 95% 以上。

只填不提交

严格只填充、不点提交 / 投递、不碰验证码，安全边界清晰，最终由你手动确认。

本地隐私优先

简历档案只存在你本机浏览器（chrome.storage），不上传任何服务器，数据始终在你手里。

投递进度追踪

内置 tracker，标黄查漏，随时知道哪些站填了、哪些还空着，复盘一目了然。

How it works

四步，从打开到填完

你负责导入数据和最终确认，重复的活交给我们。

人工收尾

你只需复核、补填个别特殊项、手动点提交。
